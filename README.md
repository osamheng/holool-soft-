# حلول سوفت

موقع عربي RTL مبني باستخدام JavaScript وVite دون أطر عمل أو مكتبات واجهة
خارجية. تنظيم الملفات الحالي يفصل الصفحات والقوالب الجزئية والبيانات والأصول،
لتسهيل نقل القوالب إلى ملفات WordPress لاحقًا.

## تشغيل الموقع

```sh
npm install
npm run dev
```

```sh
npm run lint
npm run build
```

## تنظيم المشروع

- `src/pages/`: قالب مستقل لكل صفحة، يسهل تحويله إلى قالب WordPress.
- `src/components/`: أجزاء مشتركة مثل الترويسة والتذييل وأزرار الدعوة.
- `src/data/`: بيانات الخدمات والأعمال والمقالات.
- `src/styles/`: الأنماط الأساسية وأنماط الموقع والمدونة.
- `public/assets/images/`: صور ثابتة بمسارات مستقرة، مناسبة للنقل إلى مجلد أصول القالب.
- `public/`: الملفات العامة مثل الأيقونة وقواعد إعادة التوجيه.

## تحديث مقالات المدونة

مقالات المدونة ثابتة ضمن ملفات الموقع، ولا يحتاج المشروع إلى قاعدة بيانات أو
خدمة خلفية. لإضافة مقال أو تعديله، حدّث `src/data/blogData.js` ثم أعد بناء
الموقع وانشر التغييرات.
