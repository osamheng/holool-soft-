# حلول سوفت

تطوير موقع حلول سوفت، وهو موقع عربي RTL مبني باستخدام React وVite. يتضمن صفحات
الشركة والخدمات والأعمال ومدونة تقنية مع مساحة خاصة للمحررين.

## تشغيل الموقع

```sh
npm install
npm run dev
```

```sh
npm run lint
npm run build
```

## إعداد لوحة تحرير المدونة

تحتاج لوحة التحرير إلى مشروع Supabase؛ لا تضع مفاتيح الخدمة السرية داخل تطبيق
الواجهة.

1. أنشئ مشروعًا في Supabase.
2. افتح SQL Editor وشغّل محتوى [`supabase/schema.sql`](./supabase/schema.sql).
   ينشئ الجدول وسياسات RLS التي تسمح للزوار بقراءة المقالات المنشورة فقط، وتسمح
   للمحرر بتعديل مقالات حسابه.
3. ادعُ حسابات المحررين من لوحة Supabase، ثم أضف معرّف كل محرر إلى جدول
   `blog_editors` من SQL Editor:

   ```sql
   insert into public.blog_editors (user_id)
   select id from auth.users where email = 'editor@example.com'
   on conflict (user_id) do nothing;
   ```

   عطّل التسجيل العام للمستخدمين كإجراء إضافي؛ سياسات قاعدة البيانات تسمح
   بالتحرير فقط للحسابات المدرجة في `blog_editors`. لا توجد صفحة تسجيل عام في
   الموقع.
4. انسخ [`.env.example`](./.env.example) إلى `.env.local`، ثم املأ رابط المشروع
   والمفتاح العام من إعدادات API في Supabase. لا تستخدم `service_role` في تطبيق
   Vite ولا ترسل المفاتيح السرية إلى المستودع.
5. أعد تشغيل خادم التطوير، وافتح `/admin/login` وسجّل الدخول بحساب محرر مدعو.
   من لوحة التحرير اختر **إضافة المقالات الأولية** لنسخ المقالات الأربعة إلى
   قاعدة البيانات، ثم اكتب مقالات جديدة أو احفظها كمسودات أو انشرها.
6. أضف متغيرات البيئة نفسها إلى إعدادات الاستضافة عند نشر الموقع.

إذا لم تُضبط متغيرات Supabase، تعرض صفحة المدونة المقالات الأولية المحلية، بينما
تعرض صفحة دخول المحررين تعليمات إعداد الربط.
