# حلول سوفت

تطوير موقع حلول سوفت، وهو موقع عربي RTL مبني باستخدام React وVite. يتضمن صفحات
الشركة والخدمات والأعمال ومدونة تقنية بمقالات محفوظة داخل ملفات المشروع.

## تشغيل الموقع

```sh
npm install
npm run dev
```

```sh
npm run lint
npm run build
```

## تحديث مقالات المدونة

مقالات المدونة ثابتة ضمن ملفات الموقع، ولا يحتاج المشروع إلى قاعدة بيانات أو
خدمة خلفية. لإضافة مقال أو تعديله، حدّث `src/data/blogData.js` ثم أعد بناء
الموقع وانشر التغييرات.
